## 1. 交接说明

本文件记录单个任务的执行交接状态，用于下一轮 AI 继续本任务时快速恢复上下文。

本文件不替代项目级进度总账。项目级长期状态、全局决策、跨任务阻塞、任务总览应记录在：

```text
{TASK_DOC_ROOT}/project-progress-ledger.md
```

请遵守以下规则：

- 每完成一轮执行后必须更新本文件
- 每次人工确认后必须更新本文件
- 每次阻塞、暂停、取消或目标调整后必须更新本文件
- 不要在本文件中记录密钥、Token、账号、生产环境敏感信息
- 不要把所有代码 diff 粘进本文件，只记录摘要和关键文件路径
- 如果本文件和项目总账冲突，以用户最新确认和本文件最近更新时间为准，然后同步修正项目总账

## 14. 给下一轮 AI 的硬性提醒

- 先读本文件，不要直接写代码
- 先确认当前任务状态
- 如果当前状态是“等待人工确认”，不要生成下一步 Prompt
- 如果当前状态是“阻塞”，不要继续执行，先整理阻塞问题给用户
- 如果当前状态是“暂停”或“取消”，不要继续执行，先要求用户确认
- 如果项目总账显示跨任务阻塞，不要继续执行，先要求用户确认
- 只生成当前下一步 Prompt，不要生成后续步骤 Prompt
- 生成新 Prompt 时写入 `prompts/` 下的新文件，不要覆盖或删除旧 Prompt
- 执行当前步骤时默认忽略历史 Prompt，避免旧上下文干扰
- 当前下一步执行完成后，必须更新本文件
- 如果状态、阻塞或长期决策变化，必须同步更新项目级总账
